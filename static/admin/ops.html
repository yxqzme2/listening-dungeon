System Core

Maintenance tools. Each one says what it touches.

Recommendation tags

Looks up Audible's categories and descriptions for every tracked series. Feeds the Recommendations page and the dungeon looks.

About 2–3 minutes. Don't run it back to back.

Tags + Royal Road

The same lookup, plus Royal Road tags for series it can match with confidence. Richer tags, slower.

About 10–20 minutes. Once in a while is plenty.

Generate new loot

Makes 10 new gear pieces and adds them to the loot list. They can drop in dungeons right away.

Instant.

Repair broken icons

Finds gear whose icon file is missing and gives it a working one.

Instant.
